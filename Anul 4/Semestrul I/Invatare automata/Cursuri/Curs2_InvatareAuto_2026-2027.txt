import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;


public class Main {

	public static void main(String[] args) {
		try {
			//Citim linie cu linie cu clasa BufferedReader si metoda readLine()
			FileReader fr=new FileReader("numere.txt");
			BufferedReader bfr=new BufferedReader(fr);
			//se citeste linia crt cu metoda readLine:
			int suma=0;
			int N=0;//numarul de numere din fisier
			for(;;) {
				String s=bfr.readLine();
				if(s==null)break;
				N++;
				suma+=Integer.parseInt(s);
			}
			double ma=suma/(double)N;
			System.out.println("medie="+ma);
			bfr.close(); fr.close();
		}catch(IOException e) {
			e.printStackTrace();
			System.exit(0);
		}
	}

}

Distributia gaussina Nu mai este o distributie uniforma, ci datele sunt concentrate in jurul mediei. La o distributie normala: media=mediana
  
Cum  generam numere cu o distributie gaussiana in Java?
In clasa Random, metoda nextGaussian():
public double nextGaussian()
Metoda returneaza urmatorul numar din setul cu distributie normala, generat de metoda nextGaussian(), 
set ce are media 0.0 si deviatia standard 1.0 (Deci numarul generat, poate fi si negativ !)


Aplicatie 
 Generam N de numere aleatoare cu distributie normala, ce au media aritmetica  si deviatia standard specificate.

import java.util.ArrayList;
import java.util.Arrays;
import java.util.Random;
import java.util.Scanner;

public class Main {

	public static void main(String[] args) {
		//Generam N=20 de numere cu distributie normala,
		//cu dev. standard 2.5 si cu media arirmetica 10.
		final int N=20;
		final double devStandard=2.5;
		final  double medie=10;
		double x[]=new double[N];
		Random r=new Random();
		for(int i=0;i<N;i++) {
			x[i]=10+devStandard*r.nextGaussian();
			int nr=(int)(100*x[i]);
			x[i]=nr/100.0;
		}	
		//afisare:
		for(int i=0;i<N;i++)
			System.out.print(x[i]+" ");
		System.out.println();
		//Ce deviatie standard au aceste date?
		double devStandardCalculata=calculDevStandard(x);
		System.out.println("dev. std. calculata="+devStandardCalculata);
	}
	static double calculDevStandard(double a[]) {
    	double ma=medie(a);
    	double suma=0;
    	for(int i=0;i<a.length;i++)
    		suma=suma+(a[i]-ma)*(a[i]-ma);
    	double devStandard=Math.sqrt(suma/a.length);
    	return devStandard;
    }
	static double medie(double a[]) {
    	double suma=0;
    	for(int i=0;i<a.length;i++)
    		suma=suma+a[i];
    	double ma=suma/a.length;
    	return ma;
    }

}

Cum obtinem linia dreapta , pt ca pot fi trasate mai multe linii intre puncte ?
Este dreapta pt care suma patratelor distantelor de la fiecare punct la dreapta cautata este MINIMA.


Avem un set de date (x_i,y_i). Datele sunt reprezentate grafic ca niste puncte

Alte exemple de posibile regresii liniare:
(nr de ani de experienta, salariu)
(sup. unei locuinte, chiria platita)

Putem gasi ecuatia unei drepte care "trece" printre punctele respective.
Ecuatia unei drepte: y=mx+n
m=panta
Cum calculam panta la matematica, daca cunoastem coordonatele a doua puncte de pe dreapta ?
Daca avem doua puncte (x1,y1) si (x2,y2):
y1=mx1+n
y2=mx2+n
Le scadem:
y2-y1=m(x2-x1)
Rezulta m=(y2-y1)/(x2-x1)

Pot trasa mai multe drepte!
Punctele: cat mai apropiate
Mate:Este dreapta pt care suma patratelor distantelor de la fiecare punct la dreapta cautata este MINIMA.
  Punctele disponibile sunt: (x [i],y[i])
Rezulta formula: (fara demonstratie!)
(m=Suma1/Suma2)
m=Suma( (x[i]-x_medie)*(y[i]-y_medie) ) / Suma( (x[i]-x_medie)*(x[i]-x_medie) )
 
n=y_medie-m*x_medie

Program Java pt calculul dreptei de regresie:

public class Main {

	public static void main(String[] args) {
		int x[]= {7,8,20,9,5,12,14,2,6,4};
		int y[]= {10,8,100,9,3,20,30,1,4,2};
		int N=x.length;
		//Calculam m si n, pt dreapta de regresie 
		// liniara:
		//m=Suma( (x[i]-x_medie)(y[i]-y_medie) ) / Suma( (x[i]-x_medie)^2 )
		//n=y_medie-m*x_medie
		double x_medie=medieArit(x);
		double y_medie=medieArit(y);
		double suma1=0, suma2=0;
		int i;
		for(i=0;i<N;i++) {
			suma1=suma1+(x[i]-x_medie)*(y[i]-y_medie);
                        suma2=suma2+(x[i]-x_medie)*(x[i]-x_medie);
		}
		double m=suma1/suma2;
		double n=y_medie-m*x_medie;
		System.out.println("m="+m+" n="+n);
	}
	static double medieArit(int v[]) {
		int suma=0;
		for(int i=0;i<v.length;i++)
			suma+=v[i];
		return suma/(double)v.length;
	}

}
